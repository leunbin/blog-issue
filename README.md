## 학습 흐름

1. GitHub Issue로 CS 면접 질문을 받습니다.
2. 이슈에 먼저 자신의 답변과 꼬리 질문 답변을 정리합니다.
3. 학습을 마치면 같은 식별자를 붙여 티스토리에 글을 발행합니다.
4. GitHub Actions가 RSS에서 글을 찾으면 이슈에 링크를 남기고 자동으로 닫습니다.
5. 완료한 글은 아래 표에 자동으로 누적됩니다.

> 이슈와 티스토리 제목은 반드시 같은 식별자로 시작해야 합니다.  
> 예: `[CS001] 프로세스와 스레드의 차이`
